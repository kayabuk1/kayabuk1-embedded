# kayabuk1-embedded: 自律型ライントレーサー開発プロジェクト

## 概要 (Overview)
本リポジトリは、マイコン（ATmega328P / Arduino環境）を搭載した自律型ライントレーサーの開発記録およびソースコードをまとめています。

当初は単純な条件分岐（if-else）による制御からスタートしましたが、走行の安定性を高めるために**有限状態機械（FSM：ステートマシン）**と**比例制御（P制御）**の導入に取り組みました。
ソフトウェアの論理的なバグだけでなく、モーターのストール限界や電圧降下、アナログセンサーのノイズといった**ハードウェア特有の物理的制約**にも直面し、それらを一つずつ紐解きながら解決に向けた試行錯誤を記録しています。

## ハードウェア構成 (Hardware Specifications)
- **マイコン:** ATmega328P (Arduino UNO互換)
- **モータードライバ:** DRV8835 (Dual Low-Voltage H-Bridge)
- **センサー:** 赤外線アナログラインセンサー × 3（左・中央・右）
- **回路的工夫（サージ対策）:**
  急発進・急停止に伴うモーターからの逆起電力（サージ）や電圧降下を防ぐため、モーター端子に0.1μF、ドライバーのVm-GND間に470μFの電解コンデンサを追加しました。これにより、マイコンの誤作動を軽減し、低速時のトルク出力の安定化を図っています。

## ソフトウェア・制御アーキテクチャ (Software Architecture)
- **言語:** C/C++
- **有限状態機械 (FSM) によるノンブロッキング制御:**
  `enum` と `switch-case` を用いて、ロボットの動作を状態（直進、ズレ修正、クランク旋回、コース復帰探索、向き揃えなど）として管理しています。`delay()` によるマイコンの硬直を減らし、常にセンサーを監視しながら状況判断を行う構造へと見直しました。
- **P制御（比例制御）によるライントレース:**
  左右のセンサー値の「差分（ズレの誤差）」を計算し、ズレの大きさに比例して左右のモーター速度を調整する仕組みを導入しました。これにより、オン・オフ制御で発生しやすかった蛇行（オシレーション）の軽減を図っています。
- **記憶を用いた復帰アルゴリズム:**
  コースアウト時に「最後にどちらのセンサーが線を踏んでいたか」をフラグとして記憶し、復帰動作の最初の首振りを「線があった方向」から始めることで、探索の無駄を減らす工夫を取り入れています。

## トラブルシューティングの軌跡 (Key Challenges & Solutions)
開発中に直面した数々のエラーに対し、ログの解析と仮説検証を繰り返しました。
- **グレーライン上のピストン運動（エラー8・9）:**
  センサーの可変抵抗を物理的に調整し、白紙とグレーラインの出力値に明確な差を確保しました。その上でソフトウェア側の閾値を調整し、検知漏れによるループ現象を解消しました。
- **クランクでのコースアウトとチャタリング（エラー19・23）:**
  車体が斜めのまま直進してコースアウトを繰り返す現象に対し、ラインを発見した直後に「車体が線と平行になるまで向きを揃える状態（アライメント・フェーズ）」をFSMに追加し、姿勢を整えてから前進するように改善しました。
